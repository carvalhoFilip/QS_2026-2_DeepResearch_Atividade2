# Evidências

Saídas brutas, capturas, trechos de código e logs — uma pasta por parte.

| Pasta | Parte | O que normalmente vai aqui |
|---|---|---|
| `parteA/` | Ficha da missão | Captura do commit avaliado, exportação do diagrama de fluxo |
| `parteB/` | Laboratório de contexto e prompts | Respostas das três versões de prompt em cada condição |
| `parteC/` | Verificação de fontes e saída estruturada | Respostas auditadas, páginas-fonte, saídas do validador |
| `parteD/` | Modelo de ameaças | Trechos de código que sustentam cada risco |
| `parteE/` | Testes obrigatórios | Saída bruta de cada caso de teste |
| `classificacao-falhas/` | Classificação e plano de melhoria | Material de apoio aos achados |

Para cada teste, registrar entrada, contexto, prompt, resultado esperado, resultado observado, evidência e status — consolidado em [`../resultados/casos-de-teste.csv`](../resultados/casos-de-teste.csv).

Anotar data/hora de cada execução: a busca é ao vivo e sem cache, e os resultados mudam com o tempo.

**Antes de publicar:** trajetórias de execução podem conter trechos de páginas de terceiros e, em caso de erro de configuração, fragmentos de credenciais. Revisar.
