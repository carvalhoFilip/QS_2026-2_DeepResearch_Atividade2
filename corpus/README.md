# Corpus de contexto

Documentos fabricados para cada condição. Sem eles versionados, o experimento não é reproduzível.

Cada arquivo deve registrar, no topo: origem do trecho, data de coleta e, quando houver, o que foi alterado em relação ao original.

- `A-correto/` — trecho que contém a resposta de referência
- `B-ausente/` — vazio por definição; mantido para simetria
- `C-irrelevante/` — trecho real, sem relação com a pergunta
- `D-conflitante/` — par de documentos que se contradizem sobre o mesmo fato
